# Wall of Thoughts Architecture

## Overview
The **Wall of Thoughts** is a dynamic, animated background that continuously scrolls short text snippets ("thoughts") across the screen. It is designed to be **stand‑alone**, **zero‑server**, and **easily reusable** in any HTML page.

---
### 1. Required Data Structure
- A global JavaScript array named `sotoThoughts` (or any name you prefer) must be present on the page before the wall is initialized.
- Each element should be an **object** with a `Line` property (the text to display). Example:

```js
window.sotoThoughts = [
  { Line: "Soto is deterministic" },
  { Line: "Think in parallel" },
  // ... up to 100+ lines
];
```
- You can generate this array via a static `thoughts.js` script that contains the data, or embed it directly in a `<script>` block.

---
### 2. HTML Markup (Insert where you want the wall to appear)
```html
<div class="bg-marquee-wall" id="marqueeWall">
  <!-- 24 lanes will be generated by JS -->
</div>
```
- The container **must** have the class `bg-marquee-wall` and the id `marqueeWall` (or change the ID in the script accordingly).

---
### 3. CSS (Add to your stylesheet or a `<style>` block)
```css
/* ---------------------------------------------------
   Wall of Thoughts – Core Styles
   --------------------------------------------------- */
.bg-marquee-wall {
    position: absolute;

    left: 0;

    height: calc(100vh - 60px);
    overflow: hidden;
    z-index: 1;             /* behind main UI */
    pointer-events: none;   /* clicks pass through */
    user-select: none;
    display: flex;
    flex-direction: column;
    justify-content: space-between;
    padding: 1.5rem 0;
    opacity: 0.85;           /* tweak for visibility */
}

.marquee-lane {
    display: flex;
    overflow: hidden;
    white-space: nowrap;
    width: 100%;
}

.marquee-inner {
    display: inline-flex;
    gap: 5rem;               /* spacing between thoughts */
    animation: scroll-left linear infinite;
}

.thought-text {
    color: #9CA3AF;          /* default soft‑grey, adjust as needed */
    font-size: 0.82rem;
    font-weight: 600;
    letter-spacing: -0.2px;

    0%   { transform: translate3d(0, 0, 0); }

```
- **Customization points**:
  - `color` in `.thought-text` – set any hex/RGB.
  - `font-size` – modify for larger or smaller text.
  - `gap` – change spacing between items.
  - `animation-duration` will be set per‑lane in JS (see next section).

---
### 4. JavaScript – Wall Generation
Place this script **after** the `thoughts.js` (or after the inline data) and **before** the closing `</body>` tag.
```js
/**
 * Wall of Thoughts initializer
 * ---------------------------------------------------
 * Parameters (change defaults here if you need a different layout)
 */
const WALL_CONFIG = {
    laneCount: 24,                // number of parallel scrolling rows
    itemsPerLane: 15,             // how many distinct thoughts per lane (they are duplicated for seamless looping)
    minSpeedSec: 30,             // slowest animation duration per lane
    maxSpeedSec: 80,             // fastest animation duration per lane
    minDelaySec: -40,             // smallest negative delay (starts earlier)
    maxDelaySec: 0,              // maximum delay (starts later)
    containerId: 'marqueeWall', // id of the wall container element
    thoughtsArray: window.sotoThoughts || [] // fallback to empty array – UI will stay blank
};

/**
 * Helper – shuffle an array (Fisher‑Yates).
 */
function shuffleArray(arr) {
    const copy = arr.slice();
    for (let i = copy.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [copy[i], copy[j]] = [copy[j], copy[i]];
    }
    return copy;
}

/**
 * Build the HTML for the wall.
 */
function buildWall() {
    const wall = document.getElementById(WALL_CONFIG.containerId);
    if (!wall) return console.warn('Wall container not found');
    let wallHtml = '';
    for (let i = 0; i < WALL_CONFIG.laneCount; i++) {
        const shuffled = shuffleArray(WALL_CONFIG.thoughtsArray);
        const slice = shuffled.slice(0, WALL_CONFIG.itemsPerLane);
        const listHtml = slice.map(t => `<span class="thought-text">${t.Line}</span>`).join('');
        const speed = Math.floor(Math.random() * (WALL_CONFIG.maxSpeedSec - WALL_CONFIG.minSpeedSec + 1)) + WALL_CONFIG.minSpeedSec;
        const delay = (Math.random() * (WALL_CONFIG.maxDelaySec - WALL_CONFIG.minDelaySec) + WALL_CONFIG.minDelaySec).toFixed(1);
        wallHtml += `
            <div class="marquee-lane">
                <div class="marquee-inner" style="animation-duration:${speed}s; animation-delay:${delay}s;">
                    ${listHtml}${listHtml}
                </div>
            </div>
        `;
    }
    wall.innerHTML = wallHtml;
}

// Run after DOM load
window.addEventListener('DOMContentLoaded', buildWall);
```
- **Key notes**:
  - The script **duplicates** the lane content (`${listHtml}${listHtml}`) so the scroll appears seamless.
  - Use `WALL_CONFIG` to adjust lane count, speed ranges, and container id.
  - If you need the wall in **multiple pages**, simply include the same CSS/JS files and call `buildWall()` wherever needed.

---
### 5. Re‑using the Component
1. **Copy the three parts** (HTML, CSS, JS) into the target project.
2. Ensure a `thoughts.js` (or inline script) defines the global array **before** the wall script runs.
3. Adjust `WALL_CONFIG` values to match the visual density you desire.
4. If the page already has a `DOMContentLoaded` listener, you can invoke `buildWall()` manually after that listener fires.

---
### 6. Advanced Customization (Optional)
| Feature | How to Extend |
|---------|---------------|
| **Different colors per lane** | Add a `data-color` attribute to each lane in `buildWall()` and set `.thought-text { color: var(--lane-color); }` via inline CSS variables. |
| **Dynamic thoughts source** | Replace `WALL_CONFIG.thoughtsArray` with a fetch call to a JSON endpoint (still works on `file://` if the JSON file is local). |
| **Pause on hover** | Add `.marquee-inner:hover { animation-play-state: paused; }` to CSS. |
| **Responsive lane count** | Compute `laneCount` based on `window.innerHeight` (e.g., `Math.floor(window.innerHeight / 120)`). |
